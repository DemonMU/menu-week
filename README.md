# 每周食谱管理系统

一个基于 Node.js 的每周食谱管理网站，支持菜品的增删改查、视频上传和播放功能。

## ✨ 功能特性

- 📅 **周视图**：清晰展示一周七天的食谱
- 🍽️ **三餐管理**：支持早餐、午餐、晚餐分类管理
- ➕ **菜品管理**：添加、编辑、删除菜品
- 🎬 **视频功能**：上传和观看烹饪视频
- 📱 **响应式设计**：完美支持手机、平板和电脑
- 🎨 **友好交互**：现代化的 UI 设计和流畅的用户体验

## 🛠️ 技术栈

- **后端**：Node.js + Express
- **数据库**：SQLite
- **前端**：原生 HTML/CSS/JavaScript
- **文件上传**：Multer
- **样式**：响应式 CSS

## 📦 安装与运行

### 1. 安装依赖

```bash
npm install
```

### 2. 启动服务器

开发模式（带热重载）：
```bash
npm run dev
```

生产模式：
```bash

```

### 3. 访问应用

打开浏览器访问：`http://localhost:3000`

## 🎯 使用说明

### 添加菜品

1. 点击右上角的 **"➕ 添加菜品"** 按钮
2. 填写菜品信息：
   - 菜品名称（必填）
   - 选择星期（必填）
   - 选择餐次（早餐/午餐/晚餐）
   - 菜品描述（可选）
   - 上传烹饪视频（可选，支持 MP4、AVI、MOV、WEBM 等格式，最大 100MB）
3. 点击 **"保存"** 完成添加

### 查看菜品

- 所有菜品按照星期和餐次自动分类展示
- 每个菜品卡片显示名称和描述
- 如有视频，显示 **"🎬 观看视频"** 按钮

### 编辑菜品

1. 在菜品卡片上点击 **"✏️ 编辑"** 按钮
2. 修改菜品信息
3. 可以重新上传视频（会替换原视频）
4. 点击 **"保存"** 完成修改

### 删除菜品

1. 点击菜品卡片上的 **"🗑️ 删除"** 按钮
2. 确认删除操作
3. 系统会自动删除菜品及相关视频文件

### 观看视频

1. 点击 **"🎬 观看视频"** 按钮
2. 在弹出的播放器中观看烹饪视频
3. 支持播放控制（播放/暂停、音量、全屏等）

## 🌐 API 接口

### 获取所有菜品
```
GET /api/dishes
```

### 获取单个菜品
```
GET /api/dishes/:id
```

### 添加菜品
```
POST /api/dishes
Content-Type: multipart/form-data

参数:
- name: 菜品名称
- day_of_week: 星期 (1-7)
- meal_type: 餐次 (breakfast/lunch/dinner)
- description: 描述 (可选)
- video: 视频文件 (可选)
```

### 更新菜品
```
PUT /api/dishes/:id
Content-Type: multipart/form-data

参数: 同添加菜品
```

### 删除菜品
```
DELETE /api/dishes/:id
```

## 📱 响应式支持

- **桌面端**：多列网格布局，完整功能展示
- **平板**：自适应网格布局
- **手机端**：单列布局，触控优化

## 🎨 特色功能

1. **拖放式文件上传**：支持点击选择和拖拽上传视频
2. **实时通知**：操作成功或失败时显示友好提示
3. **流畅动画**：卡片悬停效果、模态框过渡动画
4. **视频预览**：内置视频播放器，无需跳转
5. **数据持久化**：使用 SQLite 保存所有数据

## 🔒 注意事项

- 视频文件大小限制为 100MB
- 支持的视频格式：MP4, AVI, MOV, WMV, FLV, WEBM
- 删除菜品时会自动删除关联的视频文件
- 数据库文件 `menu.db` 会在首次运行时自动创建
